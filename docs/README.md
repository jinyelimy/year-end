# Docs Guide

이 폴더는 프로젝트 문서를 목적별로 읽기 쉽게 관리합니다.

## Recommended Reading Order

1. `analysis/project-analysis.md`
2. `architecture/harness-engineering-design.md`
3. 필요한 설계 문서 또는 가이드

## Folder Guide

- `analysis/`: 현재 코드베이스 상태와 구조 요약
- `architecture/`: 아키텍처, ERD, API, 엔진 설계 문서
- `guides/`: 구현/운영 가이드와 학습용 문서
- `notes/`: 날짜 기준 조사, 실험, 구현 메모
- `references/`: 외부 레퍼런스 원문 자료
- `samples/`: 샘플 입력 파일
- `images/`: 화면 캡처와 시각 자료
