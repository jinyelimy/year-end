# Validation Report Contract

## Purpose

코드 변경 이후 어떤 검증을 돌렸는지 기록하는 공통 형식을 고정한다.

## Required Sections

- `## Context`
- `## Changed Areas`
- `## Commands Run`
- `## Results`
- `## Open Questions`
- `## Files`
- `## Validation`

## Required Command Fields

- `command`
- `workingDirectory`
- `exitCode`
- `notes`

## Output File

- `.local/harness/<date>/validation-report.md`
