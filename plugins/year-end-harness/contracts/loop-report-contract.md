# Loop Report Contract

## Purpose

Agent D의 3회 테스트 루프를 동일 형식으로 남기도록 고정한다.

## Required Sections

- `## Context`
- `## Inputs`
- `## Input Scenario`
- `## Expected Result`
- `## Actual Result`
- `## Defects Found`
- `## Requested Fix`
- `## Re-validation Result`
- `## Files`
- `## Validation`

## Defect Severity

- `blocking`
- `major`
- `minor`
- `-` (결함 없음 표시용)

## Defect State

- `open`
- `resolved`
- `accepted-risk`
- `none`

## Required Defect Table Fields

- `ID`
- `Severity`
- `State`
- `Summary`
- `Owner`

## Output Files

- `.local/harness/<date>/<run-id>/loop-1-sdet-report.md`
- `.local/harness/<date>/<run-id>/loop-2-sdet-report.md`
- `.local/harness/<date>/<run-id>/loop-3-sdet-report.md`
