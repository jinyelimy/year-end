# Source Checklist

- 국세청 연말정산 안내 자료를 우선 확인한다.
- 국가법령정보센터에서 소득세법, 시행령, 시행규칙의 최신 효력을 대조한다.
- 기획재정부 보도자료는 개정 배경과 공표 시점 확인용으로만 보조 사용한다.
- 공식 출처끼리 값이 다르면 충돌 항목을 별도 섹션에 적고 구현 단계로 넘기지 않는다.
- 출처가 확인되지 않은 수치는 `inferred`로만 남기고 확정값처럼 쓰지 않는다.
- 세법 팩에는 `sourceUrl`, `publishedAt`, `effectiveAt`, `checkedAt`를 반드시 남긴다.
