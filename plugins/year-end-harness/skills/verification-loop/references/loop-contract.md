# Loop Contract Summary

상세 계약은 `plugins/year-end-harness/contracts/loop-report-contract.md`와 `plugins/year-end-harness/contracts/final-verification-contract.md`를 따른다. 이 파일은 실무 요약본이다.

## Loop Report Minimum Sections

- Context
- Inputs
- Input Scenario
- Expected Result
- Actual Result
- Defects Found
- Requested Fix
- Re-validation Result
- Files
- Validation

## Final QA Minimum Sections

- Release Decision
- Blocking Risks
- Remaining Warnings
- Files
- Validation
